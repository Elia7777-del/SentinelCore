# SentinelCore — NIST CSF 2.0 Mapping

SentinelCore is designed to support cybersecurity risk management and can be mapped
to NIST CSF 2.0 outcomes. NIST describes CSF 2.0 as guidance for organizations of
different sizes and sectors; it does not prescribe one implementation or certify a product.

| CSF Function | SentinelCore support |
|---|---|
| Govern | Policies, roles, approvals, audit records, risk reporting |
| Identify | Asset inventory, vulnerability/risk context, organization profiles |
| Protect | IAM/RBAC, MFA integration, security policies, configuration controls |
| Detect | Event collection, correlation, rules, anomaly/behavior analytics |
| Respond | Incidents, triage, playbooks, approval-controlled containment |
| Recover | Recovery workflow, evidence, backups, post-incident reporting |

This mapping must be reviewed against the deploying organization's target profile and
specific regulatory/contractual requirements.
