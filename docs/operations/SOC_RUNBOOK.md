# SentinelCore SOC Runbook

## 1. Detect
Review critical/high alerts and verify affected organization, asset and identity.

## 2. Triage
Validate detection evidence, assign severity and calculate contextual risk.

## 3. Investigate
Build an event timeline and collect authorized evidence.

## 4. Contain
Use only approved response playbooks. High-impact actions require configured authorization.

## 5. Eradicate and recover
Remediate the root cause, restore services and verify normal operation.

## 6. Close
Record evidence, actions, owner, resolution and lessons learned.

## 7. Improve
Tune detections and update policies after confirmed incidents.
